# 跨模型維護代理工作模板

你正在維護本機影片隱私處理程式。先讀 HANDOFF.md、MAINTENANCE.md、VALIDATION.md、acceptance-status.json 與相關實作。保留執行中的工作與尚未下載結果，不自動上傳私人媒體，不使用私人文字作公開範例。

每個修復循環：

1. 讀取上一個 verify_cycle 結果，重現實際失敗；以虛構或已授權的本機資料建立獨立預期結果。先證明舊程式會失敗，禁止把預期結果傳給偵測器。
2. 找到最小根因，再修改程式。優先欄位結構與內容畫素保護，避免等待完整電話、email 或姓名才開始遮。
3. 重跑單元、整合與實際 OCR／NLP 模型回歸。逐幀比較敏感核心覆蓋、空白／一般背景誤遮、密碼切換、單幀與進出通知。
4. 若失敗，依新證據繼續修正。禁止為了通過而縮小標註、刪案例、提高容許漏遮、降低覆蓋率或改掉獨立保留集。
5. 記錄版本、來源雜湊與證據範圍。更新候選套件；只有 scripts/check_release.py 通過才能發布正式套件。失敗不得覆蓋既有可回復版本。

可重跑命令：python scripts/verify_cycle.py --models MODEL_DIRECTORY。此程式負責驗證與回報，不會自行呼叫另一個 AI；宿主／CI 必須另外提供有權限限制的修復執行器。此模板本身不會啟用常駐代理或排程。

對外分開回報「程式修了什麼」「實際模型證據」「仍失敗的案例」「發布是否阻擋」。單元測試通過、一次修 bug、單一模型替換或這份模板均不等於已實現 RSI。
