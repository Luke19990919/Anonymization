# 影片隱私處理 v0.2.7rc3（待驗收）

**本候選版有已知搜尋內容漏遮與公開背景誤遮，禁止作為已通過隱私驗收的版本分享。**

**選影片 → 開始處理 → 預覽與下載。** 不需要填姓名清單、畫座標或撰寫設定檔。

目前驗證以隨附的虛構影片為主，使用者真實受測錄影尚未驗證；本版仍是需人工核對輸出的研究工具，不能宣稱任意畫面都不會漏遮或誤遮。

程式在本機逐畫面執行繁中／英文文字辨識（OCR），結合欄位標籤、格式規則與 OpenAI Privacy Filter，自動選取敏感文字的位置，套用柔化高斯模糊（Gaussian blur）。姓名依辨識結果顯示為受測者 A、B、C；不推測性別。偵測到通知卡片時會嘗試模糊整張卡片。

直接開啟 `src/video_privacy/assets/simple.html` 不會啟動服務；該頁現在會顯示啟動指引。請使用下方啟動檔。

## 1. 開啟程式

首次使用先安裝 Python 3.11 或 3.12 與 Git。解壓縮後：

- **macOS：**雙擊「啟動影片處理.command」。系統若阻擋，先檢查程式來源，或在資料夾的終端機執行 `sh start-web.sh`。
- **Windows：**雙擊「啟動影片處理.bat」。此啟動器使用已安裝的 Python 3.11。
- **Linux：**在資料夾執行 `sh start-web.sh`。

啟動器第一次會安裝套件並開啟本機處理頁，之後直接開啟。網址固定為 http://localhost:8765/；只有在執行程式的電腦上能使用。同一版本已在執行時，重複啟動會直接開啟現有頁面。更新前請先用 Ctrl+C 關閉舊版程式。macOS 安裝時保持終端機開啟；首頁開啟後可以關閉終端機，服務會在背景執行。Windows 仍須保持啟動視窗開啟。重新開機後，請再次雙擊啟動檔，等待首頁自動開啟，再放入影片；只開舊網址不會啟動服務。這是 Python 原始碼套件，尚非免安裝的獨立桌面應用程式。

若 macOS 的 `python3` 版本不符，可用 `VPF_PYTHON=python3.11 sh start-web.sh` 指定版本。已在 macOS Apple Silicon／Python 3.11 實測；Windows、Linux 啟動流程未實測。

## 2. 處理影片

1. 將一支影片拖進頁面，或點選上傳區選擇影片。
2. 按「開始處理」，等待進度完成。第一次會自動下載約 3 GB 的模型；後續重用。
3. 播放預覽，確認敏感片段已遮蔽，再按「下載處理後影片」。

輸入單檔上限 2 GB，可選 MP4、MOV、M4V、WebM、MKV 或 AVI；實際解碼支援由影片編碼決定。輸出為 H.264 MP4，**預設移除全部聲音**，避免口述個資外露。此版沒有語音辨識、局部消音或變聲。

逐畫面辨識仍可能比片長慢，建議先試短片。v0.2.3 在支援的 Mac 自動使用 Metal GPU 做 OCR，並快取完全相同畫素的小圖；不支援或失敗時使用 CPU。這台測試 Mac 的同一支 20 秒影片由 1,313.02 秒降為 374.93 秒（約 3.5 倍）；不是所有電腦或影片都會得到相同速度。首次模型下載與人工預覽不包含在此時間比較內。

你已有的十支虛構測試影片可直接拖入，不必使用其設定檔。程式不讀取資料集的標註或檔名來決定遮蔽位置。

v0.2.2 新增有邊界輸入框的畫素檢查：辨識空白及細長彩色游標，依已輸入內容遮蔽，排除 OCR 空文字假框。若看不清邊界或無法判定輸入框，仍保守遮住可能的欄位範圍；不保證所有自訂控制項、透明背景或複雜錄影都適用。

v0.2.1 修正一般文字因 OCR 信心低而被誤遮：自動模式不再單憑低信心遮蔽，仍依敏感欄位、格式與模型判斷。無法判讀又缺少敏感線索的文字可能不會被遮住，因此分享前仍需檢查。

v0.2.4 加強右側通知的短動畫保護：畫面先在記憶體短暫緩衝，辨識到通知後，向前補遮與向後延長各 0.75 秒，保護通知與右邊界之間的範圍。可能在通知前後短暫遮住背景；沒有使用測試標註或固定通知座標。此功能只保護有辨識證據的右側水平進出場，從未辨識到的通知、較長或其他方向的動畫仍可能漏遮。這是錄影後處理，不是會議即時遮蔽。

記憶體中的原畫面緩衝上限為 1.5 GiB，容量不足會停止，不會略過保護。除本來的輸入影片外，不把緩衝原畫面另寫成硬碟暫存影片。輸出仍使用你指定的柔化高斯模糊，不能保證不可逆移除。

v0.2.5 自動模式會逐幀檢查密碼欄位：確認為至少三個規則實心圓點時保留原樣；明文、旁邊顯示「隱藏」按鈕、樣式不確定或證據不足時仍遮蔽。圓點會保留密碼長度資訊。此為畫素啟發式判斷，無法讀取網站內部欄位型別；手動指定遮罩仍照常生效。帳號與通知保護不變。

## 3. 自動辨識的範圍

| 內容 | 自動處理方式 | 主要限制 |
|---|---|---|
| 姓名 | 姓名欄位、中文姓名啟發式與模型，依出現順序給 A／B／C | OCR 拼錯可能產生新代號；跨語言別名需辨識到相同證號或 email 才能連結，仍須核對 |
| email、身分證、住址 | 格式、欄位位置及模型 | 模糊、旋轉、小字與特殊排版可能漏判 |
| 帳號與密碼 | 偵測欄位標籤後保護右側值；讀不到值時擴大保護 | 無標籤的任意帳密、上下排列欄位可能漏判 |
| 通訊通知 | 通知關鍵字、卡片背景與位置啟發式 | 不保證辨識所有軟體、透明卡片或所有通知內容 |

**自動辨識可能漏遮或誤遮，模糊也不是不可逆資料移除保證。** 公開影片前請逐段檢查。若仍可讀到資料，先不要分享；可使用 [進階手動模式](ADVANCED.md) 加上已知字串與固定區域後重跑。畫面上的 QR code、文件照片、聲音等未列入全面自動辨識範圍。

## 4. 資料與分享

影片透過本機回送位址送入同一台電腦，沒有上傳至雲端推論服務。首次安裝／下載模型需要網路；本機模型齊全後可離線處理。不要將本機服務轉發至公網。

原影片檔案不會被修改。程式處理結束或失敗會刪除自己建立的上傳暫存原片；處理結果在下一支影片開始或程式關閉時清除，因此請先下載。程式不儲存原始 OCR 文字或姓名對照表到報告。異常斷電／強制終止可能留下系統暫存檔，系統與硬碟的安全仍由使用者管理。

分享整份程式 ZIP 即可；不要分享自己的 `models/`、`.venv/`、私人影片或設定檔。模型及 Python 環境不包含在壓縮檔。

## 5. 開發與驗證

命令列也可直接用自動模式：

```sh
.venv/bin/vpf redact input.mp4 --output results/processed.mp4
.venv/bin/vpf serve --port 8765 --open-browser
```

不傳 `--config` 即為自動模式；進階模式參見 [ADVANCED.md](ADVANCED.md)。

```sh
python -m pip install ".[test]"
python -m pytest
python -m build
```

實測範圍及已知限制見 [VALIDATION.md](VALIDATION.md)，元件來源見 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。合成影片測試通過不代表真實影片不會漏遮。


時間預估採近期兩分鐘速度，顯示估算區間；停滯超過一分鐘暫停預估。重新整理後速度需重新收集；新工作由伺服器提供已用時間。此為估計，非完成期限保證。CI/CD 流程與驗證界線見 CICD.md。

## 從 GitHub 原始碼建立

原始碼儲存庫不存放私人影片、模型或大型二進位資產。標準安裝器會先以固定官方提交與 SHA-256 取得 Noto Sans TC 字型；直接執行 pip install . 前請先執行 python scripts/fetch_assets.py。分享 ZIP 與建好的 wheel 仍包含字型。虛構逐字輸入影片可用 examples/regression-stacked/generate.py 重建。
